# Project image preparation

Prepared from user-supplied app captures with the built-in image editor. Bakery figures are synthetic sample data; the bakery name and badge were removed, retaining the Simargi mark. Browser chrome and transient notifications were removed for presentation. These prepared images are not pixel-exact archival captures. CRM WebP captures are supplied originals with sample leads. Raw browser captures are ignored and not published.
